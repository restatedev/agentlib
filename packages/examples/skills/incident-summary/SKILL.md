# Incident summary

Write four short paragraphs, in this order:

1. **Impact**: who was affected, how, and for how long.
2. **Cause**: the trigger and the underlying cause, without blame.
3. **Resolution**: what stopped the impact.
4. **Follow-ups**: the changes that keep it from happening again, each with an owner.

Use plain language; a reader outside engineering must follow it.
