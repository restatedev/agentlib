# Release notes

1. Group the changes into Added, Changed and Fixed. Leave out internal
   refactors and dependency bumps that users cannot notice.
2. Write each entry as one sentence about what a user can now do, not about
   the code that changed.
3. Lay out the notes as in `template.md`.
